# RimWorld Russian Translation by 2ClauZ

Русский перевод RimWorld, всех DLC и модов.

## Установка
1. Подпишитесь на мод "2ClauZ — Translation Updater" в Steam Workshop
2. Нажмите "Обновить перевод" в главном меню RimWorld

## Что входит
- `Core/` — перевод игры (Core + все DLC)
- `ModsPack/` — перевод модов (VGE, VFE, QoL и др.)
